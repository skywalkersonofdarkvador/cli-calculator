# cli-calculator

# Description
A command-line calculator built in Python that performs basic arithmetic operations. The program accepts user input, validates entries, and handles common input errors.


# Features
-Supports addition, subtraction, multiplication, and division
-Input validation to prevent crashes
-Handles division by zero errors
-Runs in a continous loop until the user exits


# Technologies Used
- Python 3
- Standard Library only

# How to Run
1. Clone the repository
2. Navigate to the project directory
3. Run:
   python cli-calculator.py

## Example Usage
User selects an operation, enters two numbers, and receives the results in the terminal.
